TravelGenie Setup & Run Guide

Instructions to run the fullstack project in your IDE (Django + React + Supabase)

📌 Before You Begin

  • Python 3.10+ installed (python.org)
  • Node.js 18+ installed (nodejs.org)
  • Your code editor of choice (VS Code, Cursor, PyCharm, etc.)
1
Open Project in Your IDE

Open the downloaded project folder in VS Code. All code, database tables, and configuration files are already configured for you.

2
Start the Backend (Django) - Terminal 1

Open a new terminal in your IDE (Ctrl + ~ in VS Code) and run the following commands:

# 1. Navigate to the server folder
cd server

# 2. Create Python virtual environment
python -m venv venv

# 3. Activate the virtual environment
# On Windows (PowerShell):
.\venv\Scripts\activate
# (On Mac / Linux use: source venv/bin/activate)

# 4. Install backend dependencies
pip install -r requirements.txt

# 5. Start the backend server
python manage.py runserver 127.0.0.1:8000
✨ Database Note: Your Supabase database is already connected inside server/.env and all tables are created. You do not need to run migrations.
3
Start the Frontend (React + Vite) - Terminal 2

Click the + button in your terminal window to open a second terminal, then run:

# 1. Navigate to the client folder
cd client

# 2. Install frontend dependencies
npm install

# 3. Start the frontend development server
npm run dev

Now open your browser and navigate to: 👉 http://localhost:5173/
